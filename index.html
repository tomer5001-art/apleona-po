📖 הוראות הגדרת סנכרון (לחץ לפתיחה)
  1. פתח sheets.google.com וצור גיליון חדש בשם PO Counter
  2. בתא A1 הכנס את המספר: 2000149
    (המספר הראשון שייווצר יהיה 2000150)
  3. לחץ על Extensions → Apps Script
  4. מחק את הקוד הקיים והדבק את הקוד הבא:
    function doGet() { const lock = LockService.getScriptLock(); lock.waitLock(30000); const sheet = SpreadsheetApp .getActiveSpreadsheet() .getSheetByName('Sheet1'); let n = Number(sheet.getRange('A1').getValue()) || 200499; n++; sheet.getRange('A1').setValue(n); lock.releaseLock(); return ContentService .createTextOutput(JSON.stringify({ po: n })) .setMimeType(ContentService.MimeType.JSON); }
    שים לב: אם שם הגיליון שלך לא Sheet1 — שנה בקוד
  5. לחץ Deploy → New deployment → Web app
  6. בשדה "Who has access" בחר Anyone ולחץ Deploy
  7. העתק את ה-URL שמופיע והדבק אותו בשדה למעלה
הכנס מספר רק אם צריך לאפס/לתקן. המספר הבא שייווצר יהיה מספר זה.
