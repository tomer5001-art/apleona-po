📖 הוראות הגדרת Apps Script (לחץ לפתיחה)
  1. פתח sheets.google.com וצור גיליון חדש בשם PO Counter
  2. בתא A1 הכנס את המספר: 2000149
    (המספר הראשון שייווצר יהיה 2000150)
  3. לחץ על Extensions → Apps Script
  4. מחק את הקוד הקיים והדבק את התוכן של APPS_SCRIPT.gs שבריפו
  5. (אופציונלי, לתרגום) Project Settings → Script Properties → Add property:
    Name: OPENAI_KEY, Value: sk-proj-...
    המפתח לא יהיה גלוי לעובדים
  6. לחץ Deploy → New deployment → Web app
  7. Execute as: Me, Who has access: Anyone → Deploy
  8. העתק את ה-URL והדבק אותו בשדה למעלה
הכנס מספר רק אם צריך לאפס/לתקן. אם Apps Script מוגדר — יעדכן גם בשרת.
